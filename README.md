## ✨ About

**Red Switcher** is a lightweight desktop tool that converts images between the most common formats with a single click. It comes with a clean dark interface and a bold red accent, and it never gets in your way: no clutter, no complicated settings, just the conversion you need.

It is especially handy for everyday icon work, where you constantly move between app icons and regular images:

<div align="center">

**`PNG`** &nbsp;⟶&nbsp; **`ICO`** &emsp;•&emsp; **`ICO`** &nbsp;⟶&nbsp; **`PNG`**

</div>

Turn any PNG into a ready-to-use Windows icon, or extract an existing icon back into a clean PNG, in just a few clicks.

Your original file is never touched. Every result is saved as a new file, so nothing gets overwritten.
